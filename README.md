# Использование кластера Yandex Managed Service for Valkey™ в качестве хранилища кеша для «1С-Битрикс: Управление сайтом»

Кластер [Yandex Managed Service for Valkey™](https://yandex.cloud/ru/docs/managed-valkey) можно использовать как внешнее хранилище кеша для сайта, развернутого при помощи «1С-Битрикс: Управление сайтом» на виртуальной машине [Yandex Compute Cloud](https://yandex.cloud/ru/docs/compute). Подготовка виртуальной машины и кластера Managed Service for Valkey, а также настройка «1С-Битрикс: Управление сайтом» описаны в [практическом руководстве](https://yandex.cloud/ru/docs/tutorials/infrastructure-management/yc-valkey-as-1c-cache-storage
), необходимый для настройки через Terraform конфигурационный файл [yc-valkey-as-1c-cache-storage.tf](yc-valkey-as-1c-cache-storage.tf) расположен в этом репозитории.
